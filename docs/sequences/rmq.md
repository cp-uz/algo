# RMQ — oraliqdagi eng kichik element

!!! warning "Tarjima holati: AI-konspekt qoralamasi"
    Bu sahifa upstream maqolaning **to‘liq satrma-satr tarjimasi emas**. Unda o‘zbekcha sarlavha va texnik konspekt bor. Isbotlar, kod namunalari, formulalar va barcha izohlar hali source bilan bandma-band tarjima qilinib, texnik hamda til tahriridan o‘tkazilishi kerak.

## G‘oya

Range Minimum Query statik yoki dinamik massivdagi [l,r] minimumini so‘raydi. Sparse table, segment tree, sqrt decomposition yoki Cartesian tree cheklovga qarab tanlanadi.

## Murakkablik

Usulga bog‘liq: sparse table O(n log n)/O(1), segment tree O(n)/O(log n).

## Qo‘llanishlar

Oraliq minimumlari, LCA, DP optimallashtirish.
