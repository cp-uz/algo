# MEX — massivdagi eng kichik mavjud bo‘lmagan element

!!! warning "Tarjima holati: AI-konspekt qoralamasi"
    Bu sahifa upstream maqolaning **to‘liq satrma-satr tarjimasi emas**. Unda o‘zbekcha sarlavha va texnik konspekt bor. Isbotlar, kod namunalari, formulalar va barcha izohlar hali source bilan bandma-band tarjima qilinib, texnik hamda til tahriridan o‘tkazilishi kerak.

## G‘oya

MEX to‘plamda yo‘q eng kichik manfiy bo‘lmagan butun son. Statik massivda mavjudlik massivi, dinamik holatda frequency va missing qiymatlar to‘plami ishlatiladi.

## Murakkablik

Statik O(n); dinamik update/query tuzilmaga qarab O(log n) yoki O(1) amortizatsiyalangan.
