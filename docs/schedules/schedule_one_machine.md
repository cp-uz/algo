# Ishlarni bitta mashinada rejalashtirish

!!! warning "Tarjima holati: AI-konspekt qoralamasi"
    Bu sahifa upstream maqolaning **to‘liq satrma-satr tarjimasi emas**. Unda o‘zbekcha sarlavha va texnik konspekt bor. Isbotlar, kod namunalari, formulalar va barcha izohlar hali source bilan bandma-band tarjima qilinib, texnik hamda til tahriridan o‘tkazilishi kerak.

## G‘oya

Bitta mashina masalalarida optimal tartib maqsad funksiyasiga bog‘liq: deadline, processing time, penalty yoki waiting time. Exchange argument qo‘shni ishlarni almashtirish orqali tanlangan sort mezonini isbotlaydi.

## Murakkablik

Ko‘p klassik variantlarda sortlash sabab O(n log n).

## Qo‘llanishlar

Job sequencing, penalty va completion-time optimallashtirish.
