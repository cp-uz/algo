# Josephus masalasi

!!! warning "Tarjima holati: AI-konspekt qoralamasi"
    Bu sahifa upstream maqolaning **to‘liq satrma-satr tarjimasi emas**. Unda o‘zbekcha sarlavha va texnik konspekt bor. Isbotlar, kod namunalari, formulalar va barcha izohlar hali source bilan bandma-band tarjima qilinib, texnik hamda til tahriridan o‘tkazilishi kerak.

## G‘oya

Doirada har k-chi odam chiqarilganda tirik qoluvchi indeks J(n,k)=(J(n−1,k)+k) mod n rekurrenti bilan olinadi. Maxsus k=2 holati bitlar orqali yopiq formulaga ega.

## Murakkablik

Umumiy rekurrent O(n) vaqt, O(1) xotira; k=2 uchun O(1).

## Qo‘llanishlar

Cyclic elimination, modular recurrence.
