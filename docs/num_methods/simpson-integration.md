# Simpson formulasi bilan integrallash

!!! warning "Tarjima holati: AI-konspekt qoralamasi"
    Bu sahifa upstream maqolaning **to‘liq satrma-satr tarjimasi emas**. Unda o‘zbekcha sarlavha va texnik konspekt bor. Isbotlar, kod namunalari, formulalar va barcha izohlar hali source bilan bandma-band tarjima qilinib, texnik hamda til tahriridan o‘tkazilishi kerak.

## G‘oya

Har juft kichik intervalda funksiya qiymatlari parabola bilan yaqinlashtiriladi va (b−a)/6·(f(a)+4f(mid)+f(b)) ishlatiladi. Composite yoki adaptive variant aniqlikni oshiradi.

## Murakkablik

Composite variant O(n) funksiya hisoblari; adaptive variant talab qilingan xatoga bog‘liq.

## Qo‘llanishlar

Sonli integral, uzluksiz funksiyalar maydoni.
