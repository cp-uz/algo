# Ikkilik qidiruv

!!! warning "Tarjima holati: AI-konspekt qoralamasi"
    Bu sahifa upstream maqolaning **to‘liq satrma-satr tarjimasi emas**. Unda o‘zbekcha sarlavha va texnik konspekt bor. Isbotlar, kod namunalari, formulalar va barcha izohlar hali source bilan bandma-band tarjima qilinib, texnik hamda til tahriridan o‘tkazilishi kerak.

## G‘oya

Monoton predikatning false va true qismlari orasidagi chegarani har qadamda intervalni teng ikkiga bo‘lib topadi. Invariant va yarim ochiq interval overflow hamda off-by-one xatolarini kamaytiradi.

## Murakkablik

O(log n) predikat chaqiruvi; javob bo‘yicha qidiruvda O(log range·cost).

## Qo‘llanishlar

Tartiblangan massiv, answer search, real sonlarda aniqlik qidiruvi.
